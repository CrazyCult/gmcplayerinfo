# Décor Manga Football

`hero-stadium.webp` et sa version mobile sont une illustration originale
créée pour ce projet avec l’outil intégré imagegen le 8 octobre 2026.
Scène : joueur original de dos, numéro 10, maillot navy/orange, stade nocturne
en encrage manga, espace central sombre, sans interface ni marques.
Le prompt complet et la recette se trouvent dans `docs/skin-manga.md`.

Les SVG de tactique et d’entraînement sont des compositions originales
réalisées dans le code du projet. Aucun personnage ou logo officiel
d’Olive et Tom/Captain Tsubasa n’est utilisé. Le logo GMC existant est conservé.

`football-burst.svg` est un dessin vectoriel original : ballon encré,
éclat orange et lignes de vitesse bleues, utilisé dans les titres de pages.
La version actuelle v3 utilise l'illustration comme vignette de l'accueil,
avec des panneaux et contrôles Manga dessinés en CSS sur toutes les pages.

La référence du pack utilisateur sert uniquement à la comparaison visuelle ;
elle n’est jamais chargée par le site.
